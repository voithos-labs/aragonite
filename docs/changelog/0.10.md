# Changelog 0.10

Newest first; the index is [`../changelog.md`](../changelog.md).

### 0.10.3: finn's uiux once over

- **Every block answers a right-click now.** A context menu opens on the block under the pointer,
  carrying what that block can actually do. Right-clicking prose with nothing selected, or the
  `+` in the gutter, opens the block menu instead: lists, quote, divider, code, table, and math
  and notes wherever those plugins are installed. It is keyboard navigable, and it inserts at the
  caret rather than at the end of the document.
- **A trailing row sits under the last block.** A document that ends in a table or a code fence
  used to be a trap: there was nothing below to click, and the way out was an arrow key you had
  to know about. Clicking the trailing row adds a paragraph, and the `+` in its gutter opens the
  block menu.
- **The table menu folds into flyouts, and strips add a row or a column.** Insert and move
  gather into Row and Column groups that open on hover or on a key; delete and alignment stay
  where they were. Hovering a table's edge reveals an add-row and an add-column strip, which
  stay pinned while the caret is in the last row or column. The menu anchors to the click and
  rides with the content when the page scrolls, and a table edit no longer scrolls the page out
  from under you.
- **The table's grips are retired.** Rows and columns move by the cell menu and by Alt+Arrow,
  which both worked already and neither of which depends on hitting a two-pixel target. Ctrl+A
  in a cell now selects the cell, then the document.
- **A code block completes its own fence, and the language picker takes a host's list.** Typing
  ` ``` ` closes the fence at once, hides the backticks and opens the picker; a fence with no body
  yet completes when you focus it, and an unfocused empty one shows nothing at all. The rail
  beside the block is restyled and sits where it should, and a host can hand the picker the
  languages its app actually supports instead of taking ours.
- **Typing the closing fence on a code block's empty last line leaves the block.** It is how
  every other editor reads that run, and ours grew the fence to four backticks instead, on the
  reasoning that owns a fence typed anywhere else: a body line reading as the closer has to be
  escaped. On the empty last line it is the exit. None of the run reaches the document, the
  fence keeps the length it had, and the caret carries on in the block below.
- **Math blocks get three layouts and a source card that matches the code block's.** The card
  hides the `$$`, highlights the LaTeX and previews as you type, so the page stops reshuffling
  under every click. The toggle picks between the layouts, and the default is set per editor or
  baked into the plugin. An empty block keeps its fill and its height, a click seats the caret at
  the end, and inline math takes the same wash as inline code while its source is showing.
- **Undo inside an open source card steps back a burst of typing, not a character.** A math
  block's revealed source kept an undo history of its own that pushed an entry per keystroke, so
  Ctrl+Z crawled there where the same keys in a paragraph walked. It batches on the same pause
  the document uses now: a run of typing comes off in one press, and Enter, a paste or typing
  over a selection each stay a step of their own.
- **Images crop, and the alt text has a menu worth reading.** Image blocks are editable rather
  than decorative now: a crop that stays inside the image's own bounds, paste support in the
  demo, and an alt menu shaped like the rest of the editor's menus.
- **Inline delimiters pair themselves.** Typing one half of `**`, `_`, `` ` `` or a plugin's own
  syntax writes the twin behind the caret; typing the closer steps over it rather than doubling
  it, whether or not the closer is visible in the mode you are in; an empty pair collapses; and
  Backspace between the two halves takes both. A plugin opts its own syntax in through the
  inline-syntax registry.
- **Drag handles are on by default.** They show for the blocks a drag actually means something
  for, stay out of tables, and stay off text-like blocks where the gesture would fight with
  selecting words.
- **Task checkboxes match GitHub's.** The box sits at the margin, fills with the text colour,
  centres its tick, and does not shift the line when you toggle it. A done item dims instead of
  being struck through.
- **Two heading and list behaviors stopped being surprising.** Enter at the very start of a
  heading moves the heading down under a new line instead of splitting it, an empty heading
  demotes to a paragraph when you leave it, and Shift+Enter inside a list item paints a real
  new line rather than a backslash.
- **Drag-select can start in the margin.** A drag beginning beside the text now selects, within
  a block or across several, and releasing keeps what you selected. The overlay merges its rects
  per line, so a widget no longer gets painted over twice, and it re-measures when a block
  changes size under it.
- **A host is told when a menu opens.** The new `menuChange` event fires on the open and close
  of the editor's own menus, so app chrome, a floating toolbar above all, can step aside instead
  of overlapping. `runCommand` also takes an argument now, for commands that need one.
- **Bold and italic come off a selection that reaches past the word.** Selecting ` word` and
  pressing Ctrl+B wrote `**word**` with the space kept outside, since a run cannot close against
  whitespace, and the same selection pressed again did nothing: the unapply read the space as
  uncovered. The toggle now reads a selection through its boundary whitespace, so a second press
  strips what the first wrote, and a toolbar asking whether the mark is on gets the same answer.
  Styled source kept that space inside the delimiters, where no reader parses it as bold and the
  next press doubled them. Every mode wraps the word alone now, a code span included, which is
  what a press across several blocks always did.
- **A block selected whole takes typing, paste and cut.** Dragging inside a rule or a rendered
  equation selects that block, and only Backspace acted on it: a character, a paste and a cut
  reached nothing, because the block holds no place for a caret and the keystroke landed on the
  editor itself. All four gestures go through the selection now — a character or a paste puts its
  own bytes where the block stood, a cut takes the block out and writes it to the clipboard, and
  each is one undo. A block emptied by any of them leaves no husk behind either: cutting an
  equation used to leave the blank line it stood on. Hosts reading `replaceBlock` see the source
  `cross-block-covered-block` where the whole-table paste reported `cross-block-paste-whole-table`.
- **The demo opens live and light.** It is the mode and the theme most people want first. The
  page is a full-width scroller with a centred column, so the document has room without the
  text running edge to edge.

### 0.10.2: an editor you can see on a white page

- **An editor with no theme of its own inherits the page's text color.** The root's text fell
  back to white whenever no host token and no `aragonite-editor-theme` wrapper set it, so the
  README's own snippet mounted white text on a fresh app's white page: you could type, and the
  spellcheck squiggle was the only sign you had. The fallback is `currentColor` now, so an
  unthemed editor reads in its page's own color, and the parrot's caption follows suit. The
  quickstart snippet gained the wrapper it always needed, saying `light` in both places that
  have to match the page.

### 0.10.1: large documents, the plugins prop, and a phone

- **A line that only becomes a heading with the line under it now joins it right away.** Pressing
  Enter in a heading standing above a bare `===` left two paragraphs on screen, though saving and
  reopening read them as one underlined heading. Any edit that puts a line directly above its
  `===` or `---` underline, or above a table's delimiter row, now folds the pair into the one
  block a reopen would show.
- **A format toggle across a giant table lands.** Selecting a table of tens of thousands of cells
  and pressing Ctrl+B did nothing at all: working out which cells the range covers handed every
  one of them to a single call, and past a certain count the engine refuses the call outright.
  The cells are gathered one at a time now, so the toggle writes, and a toolbar asking whether
  the format is already on gets an answer instead of an error.
- **A paste of a very large document lands.** Pasting more than about a hundred thousand blocks
  at once did nothing at all, for the same reason: every block went to a single call, and past a
  certain count the engine refuses the call outright. Each splice a document or a clipboard can
  scale now writes in bounded batches, so the paste lands, and so do a replace-all producing that
  many blocks and a fold over a container that wide.

- **The party parrot dances in CSS.** Its frames used to be swapped by a script timer that ran
  fourteen times a second whether or not the block was on screen, and the block's own text
  changed with every frame. All ten frames now sit in the DOM as one strip that CSS scrolls a
  frame at a time, so the dance costs no script, the bird's box stops resizing under it, and
  `prefers-reduced-motion` parks it on a single frame.

- **A plugin can say where a click lands in its own block.** `caretTargetAtPoint` was a
  descriptor field the editor read and no plugin could honestly fill: turning a press into a
  character offset means walking the DOM the way the caret does, and nothing on the plugin
  surface did it. `caretOffsetAtPoint` now does, taking one of your own elements and the press
  and answering the offset nearest it, with `CaretTarget` naming the shape the hook returns and
  `CURSOR_END` finally importable for a hook that means "wherever that leaf ends".

- **Enter works in a one-line plugin block.** Pressing it in a party parrot's caption used to
  type a newline the block had no way to show, so nothing appeared to happen. A leaf whose bytes
  are one line now says so with `createEditableLeaf`'s new `singleLine` option, and Enter ends
  the block the way it ends a heading: the text after the caret becomes a paragraph below, with
  the caret in it.
- **Decorations repaint on the keystroke that moved the text.** Marks, badges and islands
  followed the editor's batched edit event, which waits out a quarter-second typing pause, so
  an occurrence highlight visibly dragged behind the word it was painted over while you typed.
  Every decoration source now re-runs on each document change instead.
- **The occurrence highlight steps aside while you type.** Now that the marks keep up with the
  bytes, keeping up turned out to be the wrong thing to do: the word under your caret, and every
  copy of it on the page, lit up while you were still writing it. The marks clear on the first
  keystroke of a burst and come back a quarter-second after the last one, which is the editor's
  own typing pause rather than a timer the plugin brought along.
- **An editor runs only the plugins it was given.** The `plugins` prop is now the enablement
  set: an editor attaches the hooks, resolves the kinds, answers the commands and applies the
  paste transforms of exactly the plugins it lists, and a plugin another editor on the page
  installed does nothing here. Registration is still process-wide and still first-wins, and an
  editor mounted with no `plugins` prop still gets everything installed. This is how the demo
  keeps the occurrence highlight off until you ask for it: the toggle adds the plugin to the
  array.
- **A decoration source can invalidate itself from an edit handler.** `invalidate()` re-ran the
  source there and then, and an `edit` handler is called part-way through the commit that emitted
  it, so the source read a document the editor had not finished publishing. Such a call now waits
  for the commit, and several of them in one commit are one re-run. Everywhere else `invalidate()`
  stays synchronous.
- **A plugin's shortcut belongs to the editors that asked for it.** A global chord registered
  by any plugin on the page was swallowed by every editor on the page, so in an editor whose
  `plugins` array left that plugin out the key did nothing and reached neither the plugin nor
  the app around it. The chord now runs, is reported by `reservedChords()`, and is claimed by
  `claimsChord()` only in the editors that listed its plugin.
- **A paste reads the grammar of the editor it lands in.** Pasting into a paragraph, a code
  block or a table cell parsed the clipboard against every plugin installed in the process, so
  text written in a plugin's syntax became that plugin's block even in an editor whose `plugins`
  array left the plugin out, and the block then had no component to render it. Every paste route
  now parses through the same grammar the rest of that editor reads.
- **Footnote references and definitions jump to each other.** A plain click on a reference in
  reading mode, or Ctrl/Cmd+click while editing, lands the caret in the definition's body, and a
  click on the definition's `[^label]` marker lands it back after the first reference. Backspace
  at the start of a definition's body lifts that paragraph out of the note instead of doing
  nothing.
- **The party parrot ships as a bundled plugin.** `@voithos-labs/aragonite/plugins/parrot` is
  the plugin guide's quickstart, verbatim. Its caption is what you see at rest; the caret
  entering the block reveals the `%%parrot` line, and leaving it commits the edit as one undo
  entry.
- **The table's row and column grips follow `blockDragHandles`.** They painted whether or not
  the prop was on; now they show only when handles are on, like every other block's grip.
- **Typing inside a huge list or quote no longer slows down with the container.** A keystroke
  rewrites the one child's bytes inside its container's source instead of re-reading every
  child, so the cost tracks the block you are editing rather than the thousands around it. A
  25,000-item list was paying 17.7 ms per keystroke on a production build before this; it pays
  3.3 ms after, and a 250,000-item one 5.4 ms.
- **A party parrot scrolls in its own box.** The bird is wider than a phone column, and it used
  to take the whole document sideways with it, so a swipe right slid the text out from under the
  header. It scrolls itself now, the way a code block or a wide table already did.
- **Drag handles and table grips show up on a touch screen.** Both were revealed by hovering,
  which a finger never does, so `blockDragHandles` did nothing at all on a phone: the handle sat
  in the DOM permanently invisible. Where the pointer can't hover they now show at rest, and the
  grip itself takes the touch rather than the whole gutter beside it.
- **The find bar stays inside a narrow editor.** It was pinned to the right at a fixed width, so
  in a column much under 470px it ran off the left edge and the input couldn't be tapped at all.
  It now caps at the editor's width and wraps to a second row instead of overflowing.
- **Link and URL text is readable in both themes.** The accent color was one value serving a
  near-black editor and a white one, and it sat below the WCAG AA contrast line on the dark
  background and inside code blocks in either mode. It now carries a light and a dark value like
  every other color token, so links, URLs and the code fence's language label clear AA wherever
  they land. A host that declares `--color-accent` itself is unaffected.
- **Comments and keywords in a code block are readable on the fence.** The dark palette's Monokai
  pink and its comment grey both sat under the WCAG AA contrast line against the shaded background
  a code block paints behind them, and the light palette's comment grey missed it there too. All
  three keep their hue and clear AA now, on the editor surface and inside the fence.
- **Two costs paid once per block at load got cheaper.** Block identity comes off a counter
  rather than a UUID per block, and the height model seeds each block with fewer reads. Both scale
  with the block count of the whole document, which is what makes a 400,000-block load slow:
  3.2 s before, 2.0 s after, on a production build.
- **Backspace at the start of a directive's body lifts that paragraph out.** Pressed at the
  head of the first block inside a `:::name` container it did nothing at all: no bytes changed
  and the caret stayed put. It now lifts the block out above the container the way it does in a
  blockquote or a footnote, and the fences close over whatever body is left. A container whose
  first row is a title (the callouts, details) still declines the press, and now says so by
  name rather than by leaving a field out.

### 0.10.0: reload truth at every door, and windowing under host scroll

- **Host-scrolled documents window.** A page-scrolled shell (an app embedding the editor in
  its own scrolling page) now gets the same O(viewport) typing and mounting as a standalone
  editor: windowing reads a scrollport the scroll mode resolves, activation stays gated on the
  height budget alone, and a windowing editor withdraws its subtree from the host's native
  scroll anchoring and corrects by hand. `placeCaretAtPoint` below a windowed-out tail reveals
  the target before landing.
- **The live tree now converges with its own reload at every mutating door.** A demoted
  heading merges with the neighbours it stopped interrupting — above and below, with the caret
  following the typed byte; deleting an ordered list's first item folds the renumbered list
  into a tight paragraph above; a reorder, a nested edit, and a whole-body blank run under a
  callout all reload to exactly the shape they show. What a save writes is what a reopen reads.
- **A typed fence closes itself instead of swallowing the document.** Typing ` ```mermaid `,
  ` ``` `, or a math fence above other blocks mints the closing fence over an empty body; the
  blocks below stand. A gesture that merely exposes an existing open fence still folds, which
  is the reload's honest reading.
- **Whole-block kinds take AltGr, IME, and dead-key input.** A focused thematic break or
  diagram hosts a hidden editing surface on the gap caret's model, so composed and layout-mapped
  characters mint a paragraph instead of dropping; the tab order treats the block as one stop
  in each direction.
- **Footnote numbering costs the edited subtree, not the document.** With a reference mounted,
  the 1 MB keystroke p50 fell from 50 ms to 11.7 ms (100 KB: 8.2 to 4.1) by memoizing each
  top-level subtree's contribution against its bytes.
- **Three consumer doors.** `normalizeSelection` (document order over selection endpoints),
  `getBlockKindAt(path)` (the kind at a path, no DOM probing), and `canRunCommand(id)` (the
  dispatch seam's own admissibility, for greying a toolbar button) — resolved through the same
  tier walk the dispatch spends, so read and run cannot disagree. The demo toolbar rides all
  three.
- **Per-instance options reach plugin factories.** Leaf and container factories take a
  `getOptions()` thunk beside the block-command context's, and the bundled toc plugin reads its
  depth per instance, so two editors in one process render different depths.
- **Table cells follow the mode and theme.** A cell's inline widgets read the presentation
  mode and theme, and a mode flip rebuilds a cell's inline DOM the way it rebuilds a prose
  block's.
- **Paste fixes.** A pasted list ending in a table no longer takes a line ending inside the
  row; a clipboard's trailing blank line survives a paste at the document tail, in the
  document's own line-ending flavor.
- **A drag released on a whole-block kind ends there.** Releasing a selection drag over a
  thematic break or a diagram used to leave the endpoint in the block above, so the selection
  stopped short of what was highlighted; the hit test now answers with the block under the
  pointer.
- **A plugin container can declare its surface non-editable.** A container kind whose body is
  its own rendering, not text a caret belongs in, says so on its descriptor, and the editor
  treats it that way rather than making the author fake it.
- **The landable-caret guard covers every caret door.** G1.33 fires from the editor root's
  focus seam, so a plugin's own caret door and the render-primary reveal inherit the guard a
  built-in surface always had.

# Presentation: the hidden hard break

A hard break is a backslash or two-plus trailing spaces before a newline, and it keeps the next
line inside the same paragraph. A mode that hides markers hides the backslash, and trailing spaces
are blank in any mode, so the line below simply starts under the one above with nothing on screen
to say why. Where the break's bytes do not show, the editor draws a dimmed return glyph in their
place. The glyph is generated by the stylesheet, not text, so the caret, a selection and a copy
see only the break's own bytes.

Miss-analysis: the hard-break specs checked what the break writes and deletes, never what a
rendered view leaves of it, which for trailing spaces was nothing in every mode.

## Happy paths

- `one  \ntwo` pasted into live mode shows the glyph after `one`; the block's text is still the
  bytes, with no glyph in it.
- the backslash form shows the glyph in live mode too.

## Edge cases

- source mode draws the glyph for trailing spaces, which are blank there as well, and not beside
  a backslash, which source mode already shows.

## User interactions

- from the start of `two`, one ArrowLeft lands the caret at the end of `one` and one ArrowRight
  brings it back: the hidden break is one step, and the glyph adds none.
- Backspace at the start of `two` removes the break, leaving `onetwo`.

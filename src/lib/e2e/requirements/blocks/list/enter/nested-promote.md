# Block: List — Enter (nested item promote)

Enter on an empty item inside a nested list outdents one level (Shift+Tab semantics) instead of escaping to a paragraph.

## Nested promote semantics

- Enter on an empty item inside a **nested** list outdents one level. Each press promotes one level outward; only the outermost list escapes to a paragraph at the parent container level. Parallels Backspace at the start of a first-child of a nested list.
- Third Enter after promote — once the outer list is reached, a further Enter exits to a document-level paragraph
- Enter on an empty 3-level-nested item promotes exactly one level per press
